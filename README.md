# KP Global Buyer Intelligence — V1

## Included
- Company Intelligence tab
- Separate Global Dehydrated Onion/Garlic Importers tab
- Country/product/form/regular-importer filters
- Free-text search
- CSV export
- Source, verification date and confidence fields
- Data model ready for live public/licensed connectors

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

Streamlit can also be deployed to Community Cloud after putting the project in a GitHub repository.
